Base-system component presence record
=====================================

Book: Linux From Scratch 13.1-systemd
Architecture: x86_64
LFS target triplet: x86_64-lfs-linux-gnu

Status of this record:
This file replaces a previous checklist that described every marked item as
"installed and tested". That description was too strong. The previous
collector used command/file-presence probes and did not run package test
suites. Some probes were also not reliable package-identification checks.

Consequently, this record does not certify a complete package manifest, does
not report a verified count of installed packages, and does not claim that
all package tests passed.

The earlier checklist also included SysVinit and Sysklogd. They are not
presented here as required components of the systemd-based build.

For a fresh selected command/path presence report, run:
scripts/collect-evidence/check-base-system.sh

Run it inside the LFS system. Interpret its results only as presence checks.
For package test outcomes, consult the original package test logs.
