# Screenshots

This directory contains selected screenshots that provide visual evidence of important LFS build stages.

## Suggested Categories

- `host-environment/` — host and virtual-machine configuration
- `build-process/` — significant build or test milestones
- `final-system/` — booted system and final validation

## Guidelines

- Capture only screenshots that add useful technical context.
- Add a short explanation or caption where the image is not self-explanatory.
- Avoid screenshots containing passwords, tokens, personal information, or unrelated desktop content.
- Prefer terminal output that is also preserved as searchable text in the documentation or build logs.

Screenshots supplement technical documentation; they are not a substitute for commands, logs, or reproducible test results.
