# Scripts

This directory contains scripts written for the LFS project.

## Intended Contents

- Build-environment setup helpers
- Environment and prerequisite verification
- Filesystem or mount-point checks
- Log collection and test-summary helpers
- Other repeatable project-specific tasks

## Script Requirements

Every script should:

- Have a clear and specific purpose.
- State its expected execution environment.
- Explain required privileges and dependencies.
- Validate important inputs and paths.
- Fail safely and report errors clearly.
- Avoid destructive actions unless they are explicitly documented and guarded.

## Usage

Each script should include usage instructions in its comments or in a nearby documentation file.

Scripts are project helpers; they do not replace the commands and procedures specified by the relevant LFS book section. Review scripts before running them, especially when they require root privileges.
