# Primary Build Reference

## Linux From Scratch — Version 13.1-systemd

This project follows the official **Linux From Scratch 13.1-systemd** book.

| Property | Details |
|---|---|
| Book | Linux From Scratch |
| Version | 13.1-systemd |
| Edition | Systemd |
| Architecture | x86_64 |
| Target Triplet | `x86_64-lfs-linux-gnu` |
| Host OS | Fedora 43 |
| Build Environment | KVM / QEMU |
| Official Book | https://www.linuxfromscratch.org/lfs/view/13.1-systemd/ |

## How This Reference Is Used

The official LFS book is the primary reference for:

- Host system preparation
- Disk partitioning and filesystem setup
- Cross-toolchain construction
- Temporary tools
- Chroot environment
- Base system installation
- System configuration
- Linux kernel and bootloader setup

## Documentation Policy

Build procedures in this repository are based on the LFS 13.1-systemd book.

Any deviations, troubleshooting steps, test results, or additional configurations are documented separately.
